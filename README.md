# HeyFutureJasmine!

One Piece themed time capsule letter app.

## Structure
- client: React + Vite
- server: Express + MongoDB
- shared: Zod schemas

## Local setup
1. Copy server/.env.example to server/.env and fill values.
2. Install dependencies in client and server.
3. Start Redis with docker compose.

## Scripts
- client: npm run dev
- server: npm run dev
